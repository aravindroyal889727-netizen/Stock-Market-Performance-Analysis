# Stock Market Performance Analysis

> Power BI portfolio project for analyzing market performance, returns, trading volume, volatility, and moving averages.

## Project Overview

This project turns historical stock-market data into an executive-friendly analytics report. It combines data preparation, exploratory analysis, DAX measures, and Power BI storytelling to evaluate **performance and risk**.

## Analysis Areas

### Executive Overview
- Latest closing price
- Highest price
- Average trading volume
- Total trading days
- Overall return

### Performance Analytics
- Price movement over time
- Return analysis
- Trading-volume trends
- Performance comparisons

### Risk Analysis
- Daily returns
- Volatility analysis
- Risk-oriented performance indicators

### Moving Averages
- Moving-average trends
- Price versus moving-average analysis
- Trend identification

## Technology Stack

- **Power BI**: data modeling, DAX, dashboard development
- **Python**: data preparation and exploratory analysis
- **Excel**: source data and validation
- **Generative AI**: assisted development and documentation
